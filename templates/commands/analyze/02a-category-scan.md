# Stage 2A: Category Scan (Phase 1)

## Purpose

Scan 15-20% of files in EACH category to identify patterns. This phase provides a broad overview before deep-diving into priority areas.

**Time Allocation:** 25% of file analysis effort

---

## Pre-Check: Verify Previous Stage

1. Read `.analysis/.state/01-setup-and-scope.json`
2. Confirm `stages_complete` includes "setup_and_scope"
3. Load all values into memory:
   - `chain_id`
   - `project_path`
   - `analysis_dir`
   - `file_structure`
   - `tech_stack`
   - `additional_context` (if provided)

**IF state missing or incomplete:** STOP - Return to Stage 1

---

## Step 1: Load File Manifest

Read the file manifest generated by the script:

```bash
cat {analysis_dir}/file-manifest.json

```

This contains:
- All files in the project
- File sizes
- Last modified dates
- File types

---

## Step 2: Categorize Files

Group files from the manifest into these categories:

| Category | Patterns to Match |
|----------|-------------------|
| **Controllers/Routes** | `*Controller*`, `*Route*`, `*Handler*`, `*Endpoint*`, `routes/*`, `controllers/*` |
| **Services/Business** | `*Service*`, `*Manager*`, `*Provider*`, `services/*`, `business/*` |
| **Models/Entities** | `*Model*`, `*Entity*`, `*Domain*`, `models/*`, `entities/*`, `domain/*` |
| **Repositories/DAOs** | `*Repository*`, `*Dao*`, `*Store*`, `repositories/*`, `data/*` |
| **Configurations** | `*.config.*`, `*.properties`, `*.yml`, `*.yaml`, `*.env*`, `config/*` |
| **Security/Auth** | `*Security*`, `*Auth*`, `*Permission*`, `*Role*`, `security/*`, `auth/*` |
| **Middleware** | `*Middleware*`, `*Filter*`, `*Interceptor*`, `middleware/*` |
| **Utilities/Helpers** | `*Util*`, `*Helper*`, `*Common*`, `utils/*`, `helpers/*`, `common/*` |
| **Tests** | `*Test*`, `*Spec*`, `*.test.*`, `*.spec.*`, `test/*`, `tests/*`, `__tests__/*` |

---

## Step 3: Category Scan Execution

For EACH category, scan 15-20% of files (minimum 3 files per category if available).

### 3.1 Controllers/Routes Scan

---
⏸️ **[STOP: SCAN_CONTROLLERS]**

Scan files in Controllers/Routes category:

1. Select 15-20% of controller files (min 3)
2. For each file, extract:
   - HTTP endpoints (method, path)
   - Request/response DTOs referenced
   - Auth requirements (`@PreAuthorize`, `@Secured`, middleware decorators)
   - Error handling patterns
   - Validation rules

**Progress Output:**

```text
[Phase 1 - Category Scan]
Scanning Controllers/Routes...
✓ {file1}: Found {n} endpoints, Auth: {type}
✓ {file2}: Found {n} endpoints, Auth: {type}
✓ {file3}: Found {n} endpoints, Auth: {type}
...
✓ Controllers: {scanned}/{total} files scanned

```

---

### 3.2 Services/Business Logic Scan

---
⏸️ **[STOP: SCAN_SERVICES]**

Scan files in Services/Business Logic category:

1. Select 15-20% of service files (min 3)
2. For each file, extract:
   - Workflows and business rules
   - External integrations (APIs, message queues)
   - Data transformations
   - Transaction boundaries (`@Transactional`, commit/rollback)
   - Caching patterns

**Progress Output:**

```text
Scanning Services/Business Logic...
✓ {file1}: Business logic: {summary}
✓ {file2}: Integrations: {list}
✓ {file3}: Transactions: {pattern}
...
✓ Services: {scanned}/{total} files scanned

```

---

### 3.3 Models/Entities Scan

---
⏸️ **[STOP: SCAN_MODELS]**

Scan files in Models/Entities category:

1. Select 15-20% of model files (min 3)
2. For each file, extract:
   - Entity relationships (OneToMany, ManyToMany, etc.)
   - Validation constraints (`@NotNull`, `@Size`, etc.)
   - Computed properties
   - Database mappings (`@Table`, `@Column`)

**Progress Output:**

```text
Scanning Models/Entities...
✓ {file1}: Entity: {name}, Relationships: {count}
✓ {file2}: Entity: {name}, Validations: {count}
✓ {file3}: Entity: {name}, Mappings: {type}
...
✓ Models: {scanned}/{total} files scanned

```

---

### 3.4 Repositories/DAOs Scan

---
⏸️ **[STOP: SCAN_REPOSITORIES]**

Scan files in Repositories/DAOs category:

1. Select 15-20% of repository files (min 3)
2. For each file, extract:
   - CRUD patterns
   - Custom queries (JPA, SQL, NoSQL)
   - Query complexity
   - Caching strategies
   - Transaction handling

**Progress Output:**

```text
Scanning Repositories/DAOs...
✓ {file1}: Queries: {count}, Custom SQL: {yes/no}
✓ {file2}: Pattern: {CRUD/custom}
✓ {file3}: Caching: {strategy}
...
✓ Repositories: {scanned}/{total} files scanned

```

---

### 3.5 Remaining Categories Quick Scan

---
⏸️ **[STOP: SCAN_REMAINING]**

Quick scan of remaining categories (Security, Middleware, Utilities):

**Security/Auth:**
- Auth mechanism type (JWT, OAuth, SAML, Session)
- RBAC/ABAC patterns
- Password hashing

**Middleware:**
- Request/response processing
- Logging patterns
- Error handling

**Utilities:**
- Common patterns
- Date/time handling
- Validation functions

**Progress Output:**
